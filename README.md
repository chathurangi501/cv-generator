# CV Generator

A responsive web-based CV Generator System developed using HTML5, CSS3, JavaScript, PHP, and MySQL. This application enables users to create professional resumes with real-time preview, multiple templates, and PDF download functionality.

## 🚀 Features

- User Registration & Login
- Live CV Preview
- Three Professional CV Templates
- Profile Picture Upload
- PDF CV Download
- Dark / Light Mode
- Rating & Review System
- Admin Dashboard
- User Management (View & Delete Users)
- Auto CV Generation Counter
- Responsive User Interface
- Form Validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
